## (K-Means Clustering Algorithm)

Customer Segmentation Using K-Means Clustering for Market Analysis

## Dataset Information

## Dataset Name 
Mall Customers Dataset
## Dataset Link
[Kaggle] (https://www.kaggle.com/c/cifar-10/)

## Description
The dataset contains customer information, including annual income and
spending scores.

It helps businesses identify distinct customer groups for targeted marketing
strategies.

Key Features: Customer ID, Gender, Age, Annual Income (k$), and Spending Score (1-100).
